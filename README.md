# Student Grade Tracker
## Overview
Student Grade Tracker is a Java-based application developed as part of the CodeAlpha Java Programming Internship.
The application helps manage student grades, calculate performance statistics, and generate reports automatically. It allows users to enter student information, calculate average marks, identify the highest and lowest scores, and save the report to a text file.
## Features
* Add student names and marks
* Store student records using ArrayList
* Calculate average marks
* Find highest score
* Find lowest score
* Display student performance report
* Save report to a text file
## Technologies Used
* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Scanner Class
* File Handling (FileWriter)
